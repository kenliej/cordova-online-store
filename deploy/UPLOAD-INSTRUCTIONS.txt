Vercel build from .env.cpanel (edit it first if your domain differs).

cPanel backend - steps
----------------------
1. File Manager: upload cpanel/omc-backend.zip to /home/CPANEL_USER/
   Select -> Extract. Result: /home/CPANEL_USER/omc-backend
2. Upload cpanel/public_html-omc-backend.zip to /home/CPANEL_USER/public_html/
   Select -> Extract. Result: public_html/omc-backend/{index.php,.htaccess}
3. Create the MySQL database + user in cPanel (MySQL Databases).
4. Copy cpanel/env.example to /home/CPANEL_USER/omc-backend/.env and fill in:
   APP_KEY (generate), DB_*, APP_URL, APP_FRONTEND_URL, CORS_ALLOWED_ORIGINS,
   TRUSTED_HOSTS, MAIL_*.
5. In cPanel Terminal (use the EA PHP path if "php" is not found):
     cd /home/CPANEL_USER/omc-backend
     php artisan key:generate --force
     php artisan migrate --force
     php artisan user:create-admin you@yourdomain
     chmod -R 775 storage bootstrap/cache
     php artisan config:cache && php artisan route:cache
6. Add the scheduler cron from CRON.txt (every minute).
7. Test: https://kjugarap.top/omc-backend/api/health

Vercel frontend - steps (Git integration, recommended)
------------------------------------------------------
1. Push this repository to GitHub/GitLab.
2. Vercel -> Add New Project -> import the repo (Vite auto-detected, the
   repository-root vercel.json is used).
3. Environment Variables (Production + Preview + Development):
     VITE_API_BASE_URL = https://kjugarap.top/omc-backend/api
     VITE_AUTH_MODE    = token
4. Deploy. Open the Vercel URL and log in.

Vercel frontend - prebuilt folder (CLI)
---------------------------------------
  npm i -g vercel
  vercel login
  vercel deploy --prod dist-deploy/vercel
(The folder already contains a static vercel.json with SPA rewrites/headers.)

CORS
----
The backend must allow the exact frontend origin:
  CORS_ALLOWED_ORIGINS=https://YOUR-PROJECT.vercel.app
For Vercel preview URLs either add each origin or (token auth only) set
  CORS_ALLOWED_ORIGIN_PATTERNS=/^https:\/\/.*\.vercel\.app$/
